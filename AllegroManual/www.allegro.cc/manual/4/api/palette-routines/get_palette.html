get_palette

Retrieves the entire palette of 256 colors.

Description

void get_palette(PALETTE p);
Retrieves the entire palette of 256 colors. You should provide an array of 256 RGB structures to store it in. Example: 
      PALETTE pal;
      ...
      get_palette(pal);
