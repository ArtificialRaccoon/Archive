GFX_MODE_LIST

Stores an array of GFX_MODE structures.

Description

typedef struct GFX_MODE_LIST 
   int num_modes;
   GFX_MODE *mode;
Structure returned by get_gfx_mode_list, which contains an array of GFX_MODE structures.
