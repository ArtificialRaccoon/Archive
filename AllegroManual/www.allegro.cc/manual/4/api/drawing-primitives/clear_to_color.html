clear_to_color

Clears the bitmap to the specified color.

Description

void clear_to_color(BITMAP *bitmap, int color);
Clears the bitmap to the specified color. Example: 
      /* Clear the screen to red. */
      clear_to_color(bmp, makecol(255, 0, 0));
