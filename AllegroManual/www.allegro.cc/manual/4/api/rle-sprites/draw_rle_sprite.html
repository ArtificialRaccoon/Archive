draw_rle_sprite

Draws an RLE sprite.

Description

void draw_rle_sprite(BITMAP *bmp, const RLE_SPRITE *sprite, int x, int y);
Draws an RLE sprite onto a bitmap at the specified position. Example: 
      RLE_SPRITE *rle_sprite;
      ...
      draw_rle_sprite(screen, rle_sprite, 100, 100);
